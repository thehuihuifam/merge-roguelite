## 0. 검증 방식 — headless 브라우저가 없어 코드 정적 분석으로 대체

- **headless 브라우저 없음.** PATH(`chromium`, `chromium-browser`, `google-chrome(-stable)`, `chrome`, `headless_shell`, `chrome-headless-shell`, `firefox`, `msedge`), `~/.cache/ms-playwright`, `~/.cache/puppeteer`, `/opt`, `/tmp`, dpkg, Python(`playwright`/`pyppeteer`/`selenium`), 파일시스템 전체 탐색까지 확인했지만 아무것도 없었다. 지시에 따라 **재설치하지 않았다.**
- 그래서 **스크린샷은 없다**(6개 시점 모두). `docs/playtest-captures/` 에는 이 보고서만 있다.
- 대체 방법:
  1. 코드 정적 분석.
  2. 보조 수단으로, 실제 렌더 함수(`drawHud`, `drawCardOverlay`, `CardOverlayAnimator`, `drawGameOver`, `GameOverPresenter`)를 **변환 행렬을 추적하는 모의 Canvas 2D 컨텍스트**로 실행해서 draw-call 의 좌표·폰트·색·alpha 를 기록했다. 브라우저도 래스터화도 쓰지 않았다. 스크립트는 저장소 밖(`/tmp`)에서 돌렸고 커밋하지 않았다.
- 좌표는 모두 **보드 단위**(480×720)다. 1280×720 뷰포트에서는 캔버스가 480×720 CSS px, scale 1 이 되므로 보드 단위 = CSS px 이고, 캔버스 왼쪽 오프셋은 x=400 이다.
- 색은 **코드에 지정된 값(hex→RGB)이다. 스크린샷 픽셀에서 뽑은 값이 아니다.** WebGL 경로에서는 후처리(bloom 0.65 / threshold 0.55, vignette 0.22, grain 0.045, 색수차 base 0.0012) 때문에 실제 화면 픽셀값은 이와 다르다.

## 5. 게임 오버 카운트업 · NEW BEST 배지 · 색수차 (`src/render/GameOverRenderer.ts`, `GAME_OVER`)

- **카운트업:** **800ms**, `easeOutCubic`. 보간되는 것은 **값(0 → 최종 점수)뿐이다.** 50% 에 166ms, 90% 에 429ms, 99% 에 628ms 에 도달한다.
- **폰트 크기:** **60px 고정**(800 weight, `Math.round(40 × 1.5)`). 카운트업 중 크기는 변하지 않는다. 즉 "몇 px → 몇 px" 로 물으면 **60px → 60px** 이다. 진행 중 HUD 의 SCORE(40px)와 게임 오버 점수(60px) 사이를 잇는 전환 트윈도 없다. 위치는 (240, 330) center/middle, 그림자는 (5, 6, 15) blur 20.
- 값 샘플(최종 1,234 기준):

  | t (ms) | 0   | 100 | 200 | 300 | 400   | 500   | 600   | 700   | 800   |
  | ------ | --- | --- | --- | --- | ----- | ----- | ----- | ----- | ----- |
  | 값     | 0   | 407 | 713 | 933 | 1,080 | 1,169 | 1,215 | 1,232 | 1,234 |

- **NEW BEST 배지:** 132×30, 모서리 반경 15(pill 형태), 중심 (240, 236). 표시 조건은 이번 런 점수가 런 시작 시점의 best 를 **엄격히 초과**할 때다.
  - 하트비트 주기 **900ms**. `pulse = 0.5 − 0.5·cos(2π·t/900)` 으로 scale 은 **1.00 → 1.06**(t=450ms 에서 최대), shadowBlur 는 6 → 14 로 변한다.
  - 트레이스로 잰 배지 크기: t=0 에서 132×30, t=450 에서 139.92×31.80.
  - 하트비트는 끝나지 않는다. 게임 오버 화면이 떠 있는 동안 계속 반복된다.
- **색수차 펄스:** 강도 +0.014, **4회**, 발화 시점 t = 0 / 900 / 1,800 / 2,700ms(60fps 재현으로 확인). 감쇠는 τ=260ms(반감기 180.2ms). 60fps 첫 프레임의 실효 uniform 은 **0.01433**(base 0.0012 포함), 다음 펄스 직전에는 0.00164 다.
  - **위상:** 펄스가 터지는 순간 배지 scale 은 **최소(1.00)** 다. 배지가 최대(1.06, t=450ms)일 때 색수차 uniform 은 0.00353 이다. 주기는 같고 위상은 180° 어긋나 있다.
  - **채널 변위**(캔버스 480×720, I=0.01433, R/B 가 반대 방향으로 밀림): 화면 모서리 x 2.43 / y 3.65px, 좌우 가장자리 중앙 x 1.72px, 상단 가장자리 중앙 y 2.58px, **NEW BEST 배지 중심 y 0.31px**, 점수 중심 0.02px. 방사형 효과라 화면 중앙 근처에서는 거의 0 이다.
  - Canvas 2D 폴백에서는 아무 효과도 없다(no-op).
- 기타 레이아웃: 타이틀 `런 종료` 800/40 (240, 176), `최고 1,234` 600/16 (240, 398), `라운드 N 도달` 600/12 (240, 428)(라운드 구조가 있을 때만), 버튼 208×52 (136, 474)–(344, 526), 안내 문구 600/12 (240, 592).
