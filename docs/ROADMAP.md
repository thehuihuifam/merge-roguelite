# Roadmap

버전은 SemVer 를 따른다. 각 버전의 목표는 "플레이어가 느끼는 차이" 로 정의하고, 세부 태스크는 `PROGRESS.md` 가 관리한다.

## v0.1.0 — MVP 베이스라인 (현재)

**목표:** 코어 루프가 완전히 동작하고, 이후 모든 기능이 "새 파일 추가" 로 붙을 수 있는 뼈대를 만든다.

- [x] 공 생성(가중 랜덤 스폰), 조준, 드롭, Matter.js 낙하
- [x] 같은 숫자 충돌 → 합체, 연쇄 배율, 최대 티어 소멸 보너스
- [x] 점수 / 세션 베스트
- [x] 위험선 오버플로우(1초 유예) → 런 종료 → 재시작
- [x] 상태 머신(`idle → aiming ⇄ dropping`, `slowmo_select`, `game_over`)
- [x] 시드 난수와 결정적 테스트
- [x] 확장 포인트 인터페이스 9종 + no-op 기본 구현
- [x] Canvas 렌더러, 포인터/키보드 입력, 위험선 근접 비네트
- [x] CI(린트/타입/테스트), PR 템플릿, 문서 세트

**플레이어 체감:** "숫자 공 수박게임" 이 돌아간다. 차별화 요소는 아직 보이지 않는다.

## v0.2.0 — 차별화 메커니즘 1차

**목표:** 3대 메커니즘이 실제로 보이고 만져진다.

- 근접 실패 슬로우모션(`SlowMotionNearMissEffect`) 과 붉은 화면 강화
- 기본 머지 카드 덱(`BasicMergeCardProvider`): 보상 3종 + 리스크 2종
- 슬로우모션 선택 셀렉터(`CardSlowMotionSelector`) + 카드 오버레이 UI + 선택 입력
- 리스크 카드 페널티 중 `score_loss` 완전 구현, 나머지 페널티를 위한 `MergeCardContext` 필드 추가
- 발동 빈도 튜닝(분당 2~4회)

**플레이어 체감:** 합체가 터질 때 시간이 느려지고 카드가 뜬다. 그중 하나는 위험하다. 죽기 직전에 화면이 붉어진다.

## v0.3.0 — 로그라이트 구조

**목표:** 런이 "라운드" 로 나뉘고, 선택이 누적되어 런마다 다른 이야기가 생긴다.

- `IRoundSystem` 구현: 라운드별 목표 점수, 드롭 예산, 클리어 시 카드 보상
- 리스크 페널티 `spawn_larger_balls`, `raise_danger_line` 구현
- 특수 공 1종(폭탄) 과 스폰 확률
- `ISaveSystem`(localStorage): 베스트, 총 런 수, 마지막 시드
- 배율 카드의 지속 시간 관리(`ModifierStack`)
- 파티클(합체 버스트) 과 효과음(티어 비례 피치, 근접 실패 심박)

**플레이어 체감:** "이번 런은 위험선을 두 번 올리고 폭탄으로 버텼다" 같은 서사가 생긴다.

## v1.0.0 — 완성

**목표:** 처음 오는 사람이 설명 없이 10분 플레이하고 다시 오게 만든다.

- 최종 라운드 클리어 = 런 승리, 승리 화면과 통계
- 데일리 시드 모드(같은 시드로 순위 비교)
- 카드 20장 이상, 특수 공 3종, 런 간 언락(카드 해금)
- 모바일 터치 QA, 접근성(색약 팔레트, 키보드 전용 플레이), 60fps 성능 예산
- 튜토리얼(첫 런에서 슬로우모션 선택 1회 강제 노출)
- 정식 배포(GitHub Pages) 와 버전 태그

**플레이어 체감:** 수박게임이 아니라 "선택하는 머지 로그라이트" 로 기억된다.
